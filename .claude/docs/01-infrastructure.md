## Caching

- **Page caching:** enabled. `WP_CACHE` is `1`, `wp-content/advanced-cache.php` drop-in
  is present and registered as a WordPress "dropin" plugin. Provider is **WP Rocket 3.23**.
- **Object caching:** none. `wp_using_ext_object_cache()` returns `false`, and there is
  no `wp-content/object-cache.php`. All object caching is per-request only.
- **Browser caching:** **not configured.** `.htaccess` contains only the stock WordPress
  rewrite block plus an empty Really Simple Security marker. WP Rocket's usual
  `mod_expires` / `mod_deflate` / gzip block is absent, meaning either WP Rocket never
  wrote its rules or something stripped them.
- **Divi cache:** `wp-content/et-cache/` plus `wp-content/cache/et/` (Divi static CSS).
  Divi's static-CSS generation is dynamic-framework mode
  (`divi_dynamic_module_framework: on`).
- **Dead cache layer:** `wp-content/litespeed/` still exists although the LiteSpeed
  plugin is no longer installed, and the host is Apache. Inert.
