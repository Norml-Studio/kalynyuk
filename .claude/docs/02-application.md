## Plugin Interaction Map

### Dependencies
- `seo-by-rank-math-pro` **requires** `seo-by-rank-math` — both active, correct order in `active_plugins` (pro is listed first, which is fine; the pro plugin defers).
- `fast-indexing-api` is authored by Rank Math and integrates with it, but functions standalone.
- `popups-for-divi` **requires** the Divi theme — satisfied.
- `wp-mail-smtp` is what makes `gravityforms` notifications deliverable; forms work without it, email doesn't.
- `imagify` + `wp-rocket` are the same vendor (WP Media) and coordinate: Imagify produces WebP, WP Rocket serves it.
- `gravityforms` and `wp-rocket` both bundle **Action Scheduler**; only one copy loads (highest version wins). This is why `wp_actionscheduler_*` tables exist.

### Overlaps and conflicts
- **SEO:** Rank Math free + Rank Math Pro is the intended pairing, not an overlap. The real overlap is **historical** — Yoast option data and cron events survive with no plugin behind them.
- **Caching:** WP Rocket is the only live cache, but three cache layers coexist on disk: `wp-content/cache/` (Rocket), `wp-content/et-cache/` + `cache/et/` (Divi static CSS), and `wp-content/litespeed/` (**dead** — plugin uninstalled, host is Apache).
- **Deferred JS vs preloader:** `defer_all_js: 1` (WP Rocket) plus a JS-driven full-page preloader plus `divi_enable_jquery_body: on` is a fragile combination — the preloader can only hide once its own JS runs, which deferral delays. No breakage observed on production, but this is the first place to look if the site flashes or hangs on load.
- **RUCSS vs Divi:** `remove_unused_css: 1` on a Divi site is aggressive. Divi generates per-page CSS dynamically; RUCSS rewrites it. Any "styles missing on one page only" bug should start with clearing the RUCSS store (`wp_wpr_rucss_used_css`).
- **Really Simple SSL vs local dev:** RSSSL forces HTTPS, which makes `http://kalynyuk.loc` unreachable over plain HTTP and untrusted over HTTPS locally. Expect this; don't "fix" it by disabling the plugin on production.

### Extension chains
- Divi (theme) → Divi Theme Builder (bundled) → `popups-for-divi` (marketplace add-on)
- Rank Math → Rank Math Pro → Instant Indexing
- WP Rocket → Action Scheduler → RUCSS queue → `wp_wpr_rucss_used_css`
- CodeKit → `custom-code` CPT → compiled files in `wp-content/custom_codes/`
